# 4주차

## 변수
**지역변수**
- 함수 내부에서 선언
- 해당 함수 내에서만 접근 가능
- *같은 이름의 함수여도 지역 변수라면 각각의 함수 내에서만 접근 가능*

**전역변수**
- 함수 외부에서 선언
- 프로그램 어디서나 접근 가능

**지속시간**
- 자동지속기간 -> 함수 호출시 메모리 할당
- 정적지속기간 -> 프로그램 실행부터 종료까지 메모리 할당

**연결**
- 내부 연결 : static 지정자로 선언된 전역변수는 파일 내부에서만 접근 가능
- 외부 연결: extern 키워드를 사용하여 접근

**가변 매개변수**
- 매개변수 호출 시 매개변수의 개수 정해두지 않을 때 사용

## 재귀 함수
- 직접적 또는 간접적으로 자신을 호출하는 함수
- 종료조건 : 더이상 자신을 호출하지 않음
- 반복문을 사용하지 않음
